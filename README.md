# Fazal Said - Portfolio Website

Website portofolio pribadi milik Fazal Said, seorang **Backend Developer** yang berfokus pada ekosistem PHP dan framework Laravel dengan pengalaman lebih dari 7 tahun. Website ini dirancang secara khusus untuk memamerkan riwayat proyek, keterampilan teknis, dan layanan unggulan (seperti jasa pembuatan website).

## 🚀 Fitur Utama

- **Desain Modern & Responsif**: Dibangun menggunakan elemen HTML semantik dan styling berbasis utility dari **Tailwind CSS**.
- **Mode Gelap / Terang (Dark/Light Mode)**: Mendukung transisi tema dinamis yang menyesuaikan dengan preferensi sistem Anda.
- **SEO Optimized**: Sudah dilengkapi dengan *meta tag* yang sangat optimal (Title, Description, Keyword, Open Graph, Twitter Card) yang menargetkan kata kunci strategis seperti "jasa website jogja" dan "jasa bikin web murah".
- **Showcase Proyek Ciamik**: Menampilkan beragam jam terbang proyek (Sistem Informasi, E-Commerce, Landing Page) lengkap dengan stack teknologi yang direpresentasikan.
- **Micro-Animations**: Implementasi animasi CSS murni (*hover effect*, teks bergradien dinamis) demi memberikan impresi *premium* bagi pengunjung.

## 🛠️ Teknologi yang Digunakan

- **HTML5**: Struktur kerangka situs.
- **Tailwind CSS**: Styling modern menggunakan pendekatan utility-first via CDN.
- **Vanilla JavaScript**: Skrip ringan untuk menangani *toggle* tema gelap, navigasi *mobile*, dan manajemen modal.
- **Google Fonts (Fira Code)**: Estetika tipografi bernuansa *developer-friendly*.

## 📂 Gambaran Struktur

- `index.html`: Berkas utama yang memuat keseluruhan tampilan dan *logic* antarmuka portofolio.
- `logo/`: Tempat menyimpan aset logo Fazal Said dan gambar utilitas lainnya.
- `projects/`: Penyimpanan aset gambar/thumbnail dari proyek-proyek yang pernah diselesaikan.
