Soal Pertemuan 1: Membuat Landing Page Portofolio

Buatlah landing page portofolio sederhana menggunakan HTML dan CSS untuk menampilkan profil dan karya Anda sebagai developer.

Deskripsi Tugas

Buatlah sebuah landing page portofolio sederhana menggunakan HTML dan CSS. Landing page ini harus menampilkan informasi tentang diri Anda sebagai developer, dengan layout yang menarik dan responsif.

Persyaratan Teknis

  • Gunakan HTML5 semantic elements (header, nav, main, section, footer)
  • Implementasikan CSS untuk styling dan layout tanpa framework eksternal
  • Buat layout yang responsif untuk desktop dan mobile
  • Tidak menggunakan JavaScript
  • Gunakan minimal 3 warna yang harmonis
  • Sertakan gambar profil atau avatar

Konten yang Harus Ada

  • Header dengan navigasi sederhana
  • Hero section dengan nama dan tagline
  • Section tentang diri (about)
  • Section skills atau kemampuan
  • Section proyek (projects) dengan minimal 2 proyek
  • Footer dengan informasi kontak

Styling Requirements

  • Typography yang readable (gunakan font yang bagus)
  • Color scheme yang konsisten
  • Layout menggunakan Flexbox atau CSS Grid
  • Hover effects pada button dan link
  • Spacing dan padding yang proporsional
  • Box shadow untuk memberikan depth

Tips untuk Pemula

  • Mulai dengan struktur HTML terlebih dahulu
  • Gunakan CSS reset di awal file CSS
  • Buat layout mobile-first
  • Test di browser yang berbeda
  • Validasi kode HTML dan CSS Anda
  • Gunakan nama class yang deskriptif
